D'où viennent les chiffres

Lignes : wc -l vue3d/*.py. Tests : nombre de def test_ par fichier ; la suite pytest relancée le 26 novembre 2026, après la suppression des couches retirées, donne 534 réussis, 25 sautés, 0 échec en 17,4 s ; les 25 sauts sont tous dans tests/test_toits_rapides.py, marqués « Stabilisation CI ». Apports du fork : git diff --numstat be88288 main et --diff-filter=A. « Servi » : route dans vue3d/app.py ou appel depuis scene.py. Le rendu de la page n'est pas couvert par pytest : il se vérifie par outils/essai-navigateur.mjs et les scripts verifier-*.mjs. Cette page est statique : après un changement d'architecture, ses tableaux MODULES et TODOS sont à mettre à jour à la main.
